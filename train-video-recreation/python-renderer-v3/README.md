# Final v3 Renderer

A full-length 72.9-second draft renderer for the supplied train reference.

- 720×1280 vertical video
- 30 FPS / 2,187 frames
- Generated cinematic 3D train/wheel plates
- Source-inspired stick-figure character acting
- 38 frame-indexed beat map
- Original source audio used as temporary synchronization audio

The complete portable source and image assets are included in the downloadable `Train_Tires_Recreation_Final_v3_Project.zip` shared in the conversation. This repository folder documents the renderer build; the generated MP4 is delivered separately rather than committed as a large binary.

This is a first full-length draft, not a pixel-identical reconstruction. The original 3D models, rigs, camera matrices, animation curves and editable transcript were not available.
