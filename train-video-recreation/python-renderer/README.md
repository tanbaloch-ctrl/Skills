# Train Video Recreation — Render Pack

The portable Python renderer and its generated image assets are packaged in the **Train Tires Recreation Project v2 ZIP** delivered in the associated conversation.

The renderer uses Python, Pillow, NumPy and FFmpeg; the supplied source MP4 must be provided locally. See the ZIP's README for exact setup and run commands.

The current full-length render is a first procedural 2.5D/3D-asset animatic, not a pixel-identical 3D remake. The canonical frame-indexed edit list and breakdown remain in the parent project's docs folder.

See [PRODUCTION_STATUS.md](../PRODUCTION_STATUS.md) for the current render status.
